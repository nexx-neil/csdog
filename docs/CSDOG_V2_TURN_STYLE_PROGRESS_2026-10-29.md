# CSDog v2 转向步态整形进展（2026-10-29）

## 目的

900-iteration 相位步态已经能够稳定双向转弯，但操作者观察到转向姿态略拧、部分腿髋外展明显，不像成品四足常见的“收腿、抬脚、在切向踏点”的原地转向。

本阶段不覆盖通用基线，而是新增独立任务 `CSDog-V2-Turn-Style-Direct-v0`，用短训练验证可解释的转向整形约束。

## 基线诊断

新增推理指标记录：

- 每个关节的平均绝对偏差、RMS 和最大偏差；
- yaw 命令下四足在机身坐标系中的位置和横向展开量；
- 机身最大倾斜；
- 正负转向分别统计，避免平均值掩盖方向不对称。

900-iteration 基线在 `±0.30 rad/s` 转向命令下：

| 指标 | 左转 | 右转 |
|---|---:|---:|
| 实际 yaw | `+0.260 rad/s` | `-0.282 rad/s` |
| 横向串轴 | `-0.037 m/s` | `+0.007 m/s` |
| 最大机身倾斜 | `15.5°` | `13.5°` |
| 主要髋外展平均绝对角 | `0.330 / 0.284 rad` | `0.340 / 0.224 rad` |
| 髋外展最大绝对角 | `0.406 rad` | `0.369 rad` |

这与画面一致：策略主要利用约 13–23° 的髋外展和明显机身侧倾获得转矩，接触时序本身仍是正确的对角步态。

## 独立整形任务

新任务保持原来的 50 维观测、12 维动作和关节顺序，因此可以从通用 checkpoint 恢复完整优化器状态。新奖励只在 yaw 命令下启用：

1. `turn_hip_roll_excess`：髋外展偏离超过 `0.20 rad` 后才产生二次惩罚，保留必要的动态调整空间。
2. `turn_body_tilt`：抑制转向时机身 roll/pitch 倾斜。
3. `turn_foot_trajectory`：以零位足端为中心，按对角相位给出 `0.04 m` 的切向往复踏步参考；支撑足向后、摆动足向前，下一半周期交换。

训练入口增加 `--resume_path`，允许新实验从一个明确的兼容 checkpoint 恢复策略、价值网络和优化器，而不是复制文件或只加载权重。

## 50-iteration 候选结果

候选 checkpoint：

`logs/rsl_rl/csdog_v2_turn_style/2026-10-29_17-24-35_turn_style_refine50/model_final.pt`

| 指标 | 通用基线 | 整形 50 iteration | 结论 |
|---|---:|---:|---|
| 左转横向串轴 | `-0.037 m/s` | `-0.001 m/s` | 明显改善 |
| 左转最大倾斜 | `15.5°` | `13.0°` | 改善 |
| 左转主要外展平均角 | `0.330 / 0.284 rad` | `0.314 / 0.279 rad` | 小幅改善 |
| 右转横向串轴 | `+0.007 m/s` | `-0.012 m/s` | 保持良好 |
| 右转最大倾斜 | `13.5°` | `13.1°` | 小幅改善 |
| 正向转弯跌倒 | `0` | `0` | 保持 |
| 反向转弯跌倒 | `0` | `0` | 保持 |

全方向回归发现两项轻微代价：`+0.30 m/s` 前进的横漂从 `-0.078` 增至 `-0.101 m/s`，`+0.30 m/s` 左移实际速度从 `0.221` 降至 `0.198 m/s`。因此该 checkpoint 目前是供 GUI 对比的视觉候选，尚未替换通用基线。

## 下一门禁

1. 操作者对比查看整形候选的双向转弯，确认“外翻、姿态拧”的主观改善是否足够明显。
2. 如果视觉方向正确，下一轮保留整形奖励，但提高横移样本占比或加入非 yaw 行为保持约束，恢复前进和横移性能。
3. 只有视觉改善和全方向数值回归同时满足，才将整形策略升级为新的通用基线。

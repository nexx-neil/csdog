# CSDog v2 QWEASD 操控

## 一键启动

```bash
cd /home/ni/robot_projects/csdog
./scripts/play_csdog_qweasd.sh
```

Isaac Sim 窗口出现后先点击视口，使键盘焦点进入视口。

| 按键 | 命令 |
|---|---|
| `W` | 前进 |
| `S` | 后退 |
| `A` | 左移 |
| `D` | 右移 |
| `Q` | 左转 |
| `E` | 右转 |
| `Space` | 立即清除所有按键目标，随后平滑减速到零 |

按键为按住生效、松开停止，可以组合，例如 `W+Q` 前进左转、`S+E` 后退右转、`W+A` 前进左移。命令使用约 `0.20 s` 的一阶平滑，避免按下和松开时速度目标瞬间跳变。

默认速度：

- 前后：`0.35 m/s`
- 左右：`0.22 m/s`
- 转向：`0.35 rad/s`

可以临时覆盖，例如：

```bash
./scripts/play_csdog_qweasd.sh \
  --keyboard-forward-speed 0.40 \
  --keyboard-lateral-speed 0.25 \
  --keyboard-yaw-rate 0.40
```

不建议超过训练范围：前后 `0.40 m/s`、横移 `0.30 m/s`、转向 `0.40 rad/s`。

## 策略和验证

任务：`CSDog-V2-Teleop-Direct-v0`

checkpoint：

`logs/rsl_rl/csdog_v2_teleop/2026-10-29_17-42-40_qweasd_mixed100/model_final.pt`

该策略从转向整形候选恢复完整优化器状态，再训练 100 iteration。训练命令包含单轴和约 45% 双轴组合，而不是在运行时简单叠加从未见过的命令。

16 环境、每环境 1000 步固定命令结果：

| 命令 | 实际结果 | 跌倒 | 动作饱和 |
|---|---|---:|---:|
| 前进 `0.30` | `x=0.308, y=0.007 m/s` | 0 | 7.0% |
| 前进 `0.40` | `x=0.397, y=-0.014 m/s` | 0 | 7.4% |
| 后退 `-0.35` | `x=-0.318, y=0.066 m/s` | 0 | 13.0% |
| 左移 `0.15` | `y=0.146 m/s` | 0 | 10.9% |
| 右移 `-0.22` | `y=-0.250 m/s` | 0 | 17.5% |
| 左转 `0.30` | `yaw=0.287 rad/s` | 0 | 18.1% |
| 左转 `0.40` | `yaw=0.343 rad/s` | 0 | 19.8% |
| 右转 `-0.35` | `yaw=-0.405 rad/s` | 0 | 10.8% |
| `W+Q`：`x=0.30, yaw=0.30` | `x=0.298, yaw=0.287` | 0 | 16.0% |
| `S+E`：`x=-0.30, yaw=-0.30` | `x=-0.258, yaw=-0.313` | 0 | 15.8% |
| `W+A`：`x=0.30, y=0.20` | `x=0.308, y=0.145` | 0 | 7.9% |

已知限制：

- `A/D + Q/E` 同时横移和转向时，策略更偏向保证转向，横移速度会被压低。
- `0.30 m/s` 左移仍只能达到约 `0.188 m/s`，高速横移尚未完全学到。
- 转向姿态比通用基线干净，但仍有髋外展和机身略拧，不是最终成品步态。
- 这些结果针对当前 Isaac/PhysX 仿真模型；后续复杂动作和博弈继续沿纯仿真路线验证。

## 面向复杂动作和博弈的后续主线

1. 完成操控门禁：补强横移转向组合、连续变向、急停和 2–5 分钟无跌倒测试。
2. 加入仿真鲁棒性：摩擦、质量、质心、观测噪声、控制延迟和外力扰动随机化。
3. 建立动作库：趴下/起立、跌倒恢复、侧步、快速转身、扑击/躲避等独立技能。
4. 建立高层技能选择器：高层策略选择速度命令或动作技能，底层 locomotion policy 负责稳定执行。
5. 最后进入博弈：先自博弈课程和安全边界，再做对抗奖励、对手建模和多智能体评估。

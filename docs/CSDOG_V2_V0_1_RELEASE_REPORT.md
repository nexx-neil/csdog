# CSDog v2 QWEASD 仿真成果报告

版本：`csdog-v2-teleop-v0.1.0`

冻结日期：2026-10-29

范围：Isaac Sim / Isaac Lab 纯仿真，不包含实体机、ROS 控制或 sim-to-real 承诺。

## 1. 结果概览

当前版本已经在 Isaac Sim 图形窗口中完成 `W/S` 前后、`A/D` 横移、`Q/E` 转向，以及 `W+Q`、`S+E`、`W+A` 等双轴联动的人机验收。机器人会以对角腿交替步态响应连续键盘命令，命令按下和松开均经过平滑处理。

这是一个可演示、可继续迭代的 v0.1 基线，不是最终工业成品步态。当前主要观感问题是速度偏慢、转向时髋外展和机身轻微拧转、高速左移不足，以及横移和转向同时输入时横移响应偏弱。

## 2. 总体方案

控制链路为：

`WASDQE 键盘 -> 平滑后的 vx/vy/yaw 命令 -> PPO 策略 -> 12 个关节位置目标 -> 隐式 PD -> PhysX`

策略观测共 50 维：原有本体状态、命令、关节状态等 48 维，加上步态相位的 `sin/cos` 两维。策略输出 12 个关节动作，动作缩放后作为关节位置目标。步态时钟显式安排两组对角腿交替支撑和摆动，避免仅靠速度奖励形成拖行。

训练采用分阶段课程：

1. 独立导入 v2 模型，完成 URDF、关节顺序、碰撞和接触静态审计。
2. 简化碰撞体并统一四个 sole，使 30 秒 PD 站立和关节方向门禁通过。
3. 建立单轴速度课程，定位低速死区、串轴和动作饱和。
4. 增加步态相位观测、足端离地目标及对角支撑奖励，完成前后、横移和转向联合策略。
5. 增加转向姿态约束，抑制过度髋外展、机身倾斜和不合理足端轨迹。
6. 从保留优化器状态的策略继续训练 100 iteration，以 45% 概率采样双轴组合命令，形成当前 QWEASD 策略。

分阶段策略累计约 1050 PPO iteration；主要三轴步态课程为 900 iteration，随后转向整形 50 iteration、遥控混合命令精调 100 iteration。按每轮 1024 环境、每环境 24 步计，900 轮主体训练约 2212 万环境步。

## 3. 冻结参数

| 参数 | 当前值 | 作用 |
|---|---:|---|
| 仿真步长 | `0.005 s` | PhysX 更新周期 |
| 策略步长 | `0.020 s` | 每 4 个仿真步执行一次策略 |
| 观测 / 动作维度 | `50 / 12` | 含两维相位；12 个主动关节 |
| Action scale / clip | `0.35 rad / 1.0` | 限制策略关节位置修正幅度 |
| PD stiffness / damping | `40.0 / 1.5` | 关节位置目标的低层执行 |
| effort / velocity limit | `12 N·m / 10 rad/s` | 当前仿真执行器限制 |
| 目标 / 最低机身高度 | `0.386 / 0.220 m` | 姿态奖励及跌倒判定 |
| 训练 x 范围 | `+-0.40 m/s` | 前后 |
| 训练 y 范围 | `+-0.30 m/s` | 横移 |
| 训练 yaw 范围 | `+-0.40 rad/s` | 转向 |
| 双轴命令概率 | `0.45` | 让策略学习联动，不依赖运行时盲叠加 |
| 步态周期 | `0.50 s` | 对角腿交替周期 |
| 足底静止 / 摆动高度 | `0.018 / 0.050 m` | 可见抬腿目标约 3.2 cm |
| tracking std | `0.25 / 0.25` | 线速度 / yaw 跟踪灵敏度 |
| 键盘默认 x/y/yaw | `0.35 / 0.22 / 0.35` | m/s、m/s、rad/s |
| 键盘平滑时间 | 约 `0.20 s` | 减小骤按、骤松冲击 |

核心奖励缩放为：x/y/yaw tracking `+4/+4/+4`，对应 L2 误差 `-5/-5/-2.5`，支撑足接触 `+2.0`，摆动足释放 `+0.5`，摆动足高度 `+1.5`，足底滑动 `-0.25`，非命令轴速度 `-6.0`，站立偏移 `-1.0`，动作幅值/变化/溢出 `-0.08/-0.02/-0.10`。转向精调额外加入髋外展、机身倾斜和切向足端轨迹约束。

这些是当前 Isaac/PhysX 模型的有效仿真参数。电机型号虽计划使用宇树 GOM8010-6，但本文的 `12 N·m`、`10 rad/s` 和 PD 参数不能解释为实体电机连续额定参数。

## 5. 关键修改及原因

- 将 v2 资产和任务与旧 v1 完全隔离，避免错误复用质量、关节顺序、站高和 checkpoint。
- 为四条腿建立独立 sole 接触体并简化碰撞网格，使接触奖励和足底滑动测量具有明确物理含义，同时降低并行仿真负担。
- 把观测从 48 维扩展为 50 维，加入步态相位，让策略能区分“当前应支撑还是应摆动”。旧 48 维 checkpoint 因此不能误加载。
- 修复命令采样写回和奖励捷径，避免策略通过静止、串轴或低姿态获取不合理高奖励。
- 将足端奖励分为支撑接触、摆动释放和摆动高度，促成肉眼可见的对角抬腿。
- 加大非命令轴惩罚，降低动作幅值与溢出，减少漂移、串轴和长时间饱和。
- 对转向增加髋外展、机身倾斜、足端切向轨迹约束，改善原地转向，但仍保留适度髋自由度。
- 遥控精调显式训练双轴组合，并加入约 `0.20 s` 命令平滑，使键盘操控连续可用。

## 7. 同环境电脑复现

验证环境：Ubuntu 22.04.5、Python 3.11.16、Isaac Sim 5.1.0.0、Isaac Lab 工程 commit `37ddf626871758333d6ed89cf64ad702aef127d0`、PyTorch 2.7.0+cu128、RSL-RL 3.1.2、Gymnasium 1.2.1、RTX 4060 Laptop、NVIDIA driver 580.178.04。

下载完整资源包后：

```bash
tar -xzf csdog-v2-teleop-v0.1.0-complete.tar.gz
cd csdog-v2-teleop-v0.1.0
conda activate dogfight
python -m pip install --no-deps -e source/stackforce_simready_generated_robot_lab
./scripts/play_csdog_qweasd.sh
```

窗口出现后点击 Isaac Sim 视口，再按住 `W/S/A/D/Q/E`。如果环境名不是 `dogfight`，可用：

```bash
CSDOG_CONDA_ENV=你的环境名 ./scripts/play_csdog_qweasd.sh
```

资源包不会携带 Isaac Sim、Isaac Lab、显卡驱动或 Conda 环境；这些大型依赖需在目标电脑预先按相同版本安装。若版本、GPU、PhysX 设置或依赖不同，轨迹可能有差异。

## 8. 下一阶段建议

以此标签作为只读基线，下一版本优先处理三件事：补强 `A/D + Q/E` 联动训练；用更强的髋外展和躯干偏航姿态约束精修转向；加入连续变向、急停和 2–5 分钟无跌倒验收。之后再建立起立、倒地恢复、快速转身、扑击和闪避等动作库，为高层技能选择及自博弈做准备。
